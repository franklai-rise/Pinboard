# Pinboard 0.7.3 — A lighter, quieter workspace / 更轻、更简洁

## English

This release brings daily collection, a calmer interface, and a lighter background receiver to Pinboard.

- Daily screenshot and text boards, independent fixed receiving targets, custom text folders and boards.
- A simplified toolbar, contextual sidebar actions, a refreshed logo, and softer text cards.
- A working jump-to-bottom button that preserves zoom, plus better history grouping and display names.
- The browser canvas is loaded only when needed and released after about 15 seconds hidden or minimized, after confirming saves. Clipboard collection keeps running and the reading position is restored on return.
- Board switching releases old image caches; document loading skips image blobs referenced only by recovery history.
- English and Chinese README pages, public demo screenshots, and improved portable-package documentation.

**Get started:** download `Pinboard-windows-x64.zip`, extract it, and run `Pinboard.exe`. Keep PixPin running for the usual `Ctrl+Alt+A` → copy workflow. Text collection requires explicit opt-in in Settings on new installations; choose Daily for a new text board each day. Existing preferences are preserved.

**Verified:** 54 .NET tests, 14 frontend tests, and 14 local desktop smoke checks. One machine's tray working-set sample fell from 646.9 MB to 168.9 MB after opening and hiding a board; this is not a universal memory guarantee. Large-board stress and the full multi-monitor/high-DPI matrix remain unverified.

**Before upgrading:** exit Pinboard normally, back up your `.pinboard` files and local preferences, then replace the program files. The portable build includes .NET but requires Windows x64 and WebView2. It is unsigned. Board files are not encrypted; privacy filtering is best-effort.

## 简体中文

本次更新加入每日收集、更简洁的界面和更轻的后台运行方式。

- 截图、文字可每天自动接收至新画板，分别支持固定目标；文字可新建文件夹与手动画板。
- 精简顶部工具栏、按需显示侧栏操作，更新 Logo 与灰白文字卡片。
- 修复“一键到底”，保持缩放；完善历史分组与显示名称。
- 按需加载浏览器画布；隐藏或最小化约 15 秒后，确认保存再释放资源。后台收集照常运行，重新打开时恢复阅读位置。
- 切换画板时释放旧图片缓存；打开文档不再加载只被恢复历史引用的图片资源。
- 补齐中英文介绍、公开演示截图和便携包文档。

**使用方法：** 下载 `Pinboard-windows-x64.zip`，解压并运行 `Pinboard.exe`。截图照常使用 PixPin 的 `Ctrl+Alt+A`，完成后复制即可。全新安装需在设置中明确开启文字收集，想每日自动新建文字板时请选择“每天一张”；升级保留已有偏好。

**验证结果：** 54 项 .NET 测试、14 项前端测试和 14 项本机桌面检查通过。一次本机样本中，后台工作集从 646.9 MB 降至打开画板再隐藏后的 168.9 MB；这不是普遍内存保证。大画板压力测试与完整多屏高 DPI 测试仍待专项验证。

**升级前：** 正常退出程序，备份画板和本机设置，再替换程序文件。便携版自带 .NET，需要 Windows x64 与 WebView2，暂未代码签名。画板本身未加密，隐私过滤也不能保证识别所有敏感信息。
