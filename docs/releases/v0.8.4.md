# Pinboard v0.8.4

## 中文

本次汇总 v0.7.3 之后的本机功能升级，并改进侧栏点击反馈。

- **更清晰的侧栏交互**：箭头悬停显示手形和淡蓝色圆角高亮，按下轻微收缩，展开时平滑旋转。点击标题也能展开，新建按钮独立操作，列表位置保持稳定。
- **轻量文字阅读**：原生阅读视图、关键词高亮、本机收藏和重复内容折叠；切换到画布继续编辑。折叠仅影响显示，每次复制记录仍保留。
- **收录与搜索优化**：截图增量传输、持久化收录与 OCR 队列、搜索结果摘要和键盘定位。任务恢复保留原始收录日期。
- **AI 对话资料库**：本机标题目录、独立子对话勾选、筛选后全选、版本恢复及可选 Google Drive 备份。新增进度、问题分类、定向重试和只读重复检查。
- **依赖升级**：更新 .NET、WebView2、图像处理与前端构建依赖；Windows x64 便携包包含所需 .NET 运行时。

### 使用与升级

下载 `Pinboard-windows-x64.zip`，解压后运行 `Pinboard.exe`。升级时先从托盘退出旧程序，再替换程序文件。画板和本机设置单独保存；建议升级前备份资料库。Windows 10 build 19041 或更新版本，以及 WebView2 Runtime 仍为必需条件。

新安装默认关闭文字收集。Google Drive 需导入自己的桌面 OAuth 配置并独立授权，只上传明确勾选的对话；原始记录没有额外加密。缺失源文件或图片会明确显示不完整状态，不能通过重复点击备份补回已删除的内容。

### 验证

- 156 项 .NET 自动测试通过，覆盖侧栏命中区域、独立新建按钮、禁用光标、布局、备份和收录回归。
- 本机已实测箭头及标题展开/收起、新建菜单独立操作和高亮恢复。
- 发布流程重新运行前端测试、网站测试、依赖审计、公开源码隐私检查和 Windows 便携构建。
- Google Drive 真实账号连接及上传/下载恢复需在各自账号内单独验证；发布测试不代表任何用户的全部备份已完成。

## English

This release brings together the local improvements since v0.7.3 and adds clearer sidebar interaction feedback.

- **Responsive sidebar**: hand cursors, rounded blue hover highlights, subtle press feedback and rotating disclosure arrows. Titles also expand groups, while add buttons remain independent and rows stay in place.
- **Lightweight text reading**: native reading view, search highlights, local favorites and display-only duplicate grouping. Switch to the canvas to edit; every captured record remains stored.
- **Capture and search reliability**: incremental image transfer, durable capture and OCR queues, contextual result snippets and keyboard navigation. Recovered work keeps its original capture date.
- **AI Sessions library**: local title discovery, independent child selection, filtered bulk selection, version recovery and optional Google Drive backups. Progress, issue categories, targeted retries and read-only duplicate checks help track unfinished work.
- **Updated dependencies**: .NET, WebView2, image processing and frontend tooling. The Windows x64 portable package includes the .NET runtime.

### Install and upgrade

Download `Pinboard-windows-x64.zip`, extract it and run `Pinboard.exe`. Exit the previous app from its tray menu before replacing program files. Boards and local settings are stored separately; back up your library before upgrading. Windows 10 build 19041 or newer and WebView2 Runtime are required.

Text collection is off on fresh installations. Optional Drive backup requires your own desktop OAuth configuration and separate authorization; only explicitly selected sessions are uploaded, without additional encryption of raw records. Missing source files or images remain clearly labelled as incomplete.

### Validation

156 .NET tests pass, including sidebar hit areas, independent add actions, disabled cursors, layout, backup and capture regressions. The installed sidebar's expansion, independent add menu and hover reset were checked on Windows. Release checks rerun frontend/website tests, dependency audits, public-source privacy checks and the portable build. Each Google account still needs its own live upload/download recovery verification.

The SHA-256 sidecar can verify the downloaded ZIP. Builds are currently unsigned.
