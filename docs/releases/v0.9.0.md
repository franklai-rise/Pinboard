# Pinboard v0.9.0

## 中文

- 修复悬停提示的文字与背景对比度，优化侧栏字体、截图与文字分区，以及每日画板的“今日”标记。
- 新增纯净模式；画布可只读浏览，文字阅读界面可隐藏工具，按 Esc 返回。
- 侧栏和文字阅读区的边界可拖动调整，双击恢复默认，宽度保存在本机。
- 现有项目可经确认放入回收站；默认项目不会删除资料库根目录或自动截图、文字画板。
- 排除图片和 Excalidraw 内部剪贴板数据，普通文字与代码仍可收集。

下载 Windows x64 ZIP 并解压运行。升级前请从托盘退出旧程序并备份资料库。需要 Windows 10 19041 或更新版本及 WebView2 Runtime；程序未签名。Google Drive 备份需要单独授权，原始对话没有额外加密。

## English

- Readable hover tips, larger sidebar labels, distinct screenshot and text sections, and Today labels for daily boards.
- Focus mode hides tools for read-only canvas viewing or native text reading; press Esc to return.
- Drag either pane divider to resize and double-click to reset. Layout preferences remain local.
- Recycle existing projects after confirmation; the default project's action protects the library root and automatic boards.
- Exclude image and internal Excalidraw clipboard payloads while preserving ordinary text and code collection.

Download and extract the Windows x64 ZIP. Exit the prior app from the tray and back up the library before replacing it. Windows 10 build 19041 or later and WebView2 Runtime are required. The app is unsigned. Optional Google Drive backup requires separate authorization and uploads raw conversations without additional encryption.

Local verification: 167 .NET tests and 104 isolated desktop checks passed; one symbolic-link test was skipped because Windows denied the required privilege. The release workflow repeats the build and tests.
