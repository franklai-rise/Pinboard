# Pinboard 0.8.5 — 侧栏与纯净浏览

- 截图、文字剪藏和现有项目分别显示；每日画板标注“今日 / Today”，按月份折叠。月份只是界面分组，每日文件仍独立保存。
- 侧栏字体放大。两条竖向边界可以左右拖动，双击恢复默认，调整后的宽度会保存在本机。
- 顶部“纯净模式 / Focus”隐藏当前内容区域的工具。在画布中只读浏览、平移缩放；在原生文字阅读中保留卡片和正文。再次点击或按 Esc 恢复。
- 项目标题的右键或“⋯”菜单可以将整个项目放入回收站。确认框显示路径和文件数量；默认项目只处理普通根目录画板，不包含截图、文字目录及早期自动画板。
- 已移除新建项目入口；新建画板可选择已有项目。文字模块的“＋”提供新建文字画板和文件夹。
- 统一浅色圆角悬停提示，修复文字颜色冲突。过滤图片和 Excalidraw 内部复制数据，避免它们成为文字卡片；已有卡片保留。

保存位置可点击侧栏底部路径打开，也可在设置中查看。新安装默认使用 Windows“文档”目录中的 Pinboard；升级沿用已有设置。实际文件仍保存在原位置，界面分组不会移动文件。

## English

Screenshots, Text Clips and existing projects now have distinct sections, larger labels, Today badges and month groups. Month groups do not combine daily files. Drag either vertical divider to resize the panes; double-click to reset. Layout preferences stay in the local profile.

Use **Focus** to hide tools without losing your position. The canvas becomes read-only, while native text reading keeps its list and full text. Click **Exit focus** or press **Esc** to return.

An existing project's menu can move it to the Recycle Bin after confirming its path and file counts. The virtual default project never deletes the library root or automatic screenshot/text boards. New project creation has been removed; boards can still be added to existing projects.

Hover tips now use a readable light surface. Image and internal Excalidraw clipboard payloads are excluded from new text capture; ordinary text, code, JSON and deliberate repeated copies remain supported.
