# Pinboard 0.7.4 — 查找更快，阅读更轻

## 使用变化

- 文字画板默认使用原生阅读模式，不启动浏览器画布。左边选择时间卡片，右边阅读完整原文；右上角“画布 / 阅读”可切换。
- 搜索摘要围绕命中关键词展示并高亮；全库可按相关性或最近修改排序，方向键选中、Enter 打开。长文字定位到关键词附近的可读位置。
- 阅读视图支持本机星标收藏和仅显示收藏。重复内容折叠只改变显示，每次复制的记录仍独立保留。
- 窗口底部同时显示截图与文字接收状态，点击可分别暂停、打开目标或恢复每日接收；托盘中也有独立的暂停入口。
- 侧栏按变化更新行，不反复清空整张列表；展开状态按稳定分组 ID 保存，不受界面语言影响。

## 内存与可靠性

- 活动画板仅传送新增图片，不再为每张新截图重新编码已缓存的全部图片。
- 单个串行 OCR 工作器按需读取当前原图；等待任务保存在本机，不由大量等待任务持有图片数组。
- 原生文字阅读只创建一个完整原文控件，时间列表使用虚拟化。
- 每次收录先保存原始内容、确定的接收路径、复制时刻和独立事件 ID。跨日处理仍归入复制当天；恢复重放同一个事件不重复添加，真正的重复复制仍分别添加。
- 图片 OCR 失败不会影响已保存的图片；原图保留在本机 OCR 队列中，后续可重试。
- 文字收录只更新新增条目的索引，常规场景使用更快的兼容压缩格式。

## 本机文件

画板保存目录不变，可在设置里查看完整路径和打开文件夹。

恢复队列位于本机配置目录的 `Recovery/CaptureInbox`，OCR 原图任务位于 `OcrQueue`，收藏位于 `text-favorites.json`。这些内容可能含有个人信息，不应上传 GitHub；软件不会自动上传。任务处理成功后删除对应临时内容。

自动化验证使用合成数据和独立配置目录，不读取或公开个人剪贴板记录。

- .NET 自动测试：97 项通过，连续两次全量验证。
- 前端自动测试：20 项通过。
- 官网搜索演示：3 项通过，并在浏览器中验证中文搜索、Enter 定位和当前缩放保持。
- 桌面集成：35 项通过，包含原生阅读无 WebView、打开不改写画板内容、长文字定位、增量图片缓存、重复复制、隐藏收录及保存后释放画布。
- 最终发行版构建完成，依赖审计为 0 漏洞，公开源码隐私扫描通过；最终桌面复验通过。
- 本机部署已完成，运行版本为 0.7.4.0。程序校验与构建产物一致，23 个旧画板在替换前完成逐文件校验备份，部署过程中原文件未变化，语言、隐私及接收偏好保持不变。

Windows 普通剪贴板监听无法恢复在通知被处理前已被下一次复制覆盖的内容。缺少系统 OCR 语言包时，对应原图任务将保留等待重试，占用磁盘而非排队内存。收藏与阅读视图不是画板内容的替代备份，仍应备份 `.pinboard` 文件。

本轮先交付本机构建与部署，GitHub 推送及 Release 发布另外安排。性能测试使用合成数据，不构成所有设备上的固定性能保证。
