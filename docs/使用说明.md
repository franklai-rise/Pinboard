# Pinboard 使用说明

## 普通 PixPin 截图自动收录

Pinboard 不修改 PixPin 程序或它的个人配置。只要 Pinboard 正在运行（窗口打开或隐藏在系统托盘均可），它只观察 `Ctrl+Alt+A`，不会占用或改变 PixPin 的快捷键。

Pinboard 默认在登录 Windows 后静默启动到系统托盘，因此不需要每次手动打开。可在“设置 → 截图接收”中取消勾选“登录 Windows 时启动 Pinboard”。

日常流程：

1. 像平时一样按 PixPin 的 `Ctrl+Alt+A`。
2. 正常框选、标注或调整截图。
3. 用你原来的复制动作完成截图：按 `Enter`、`Ctrl+C` 或点击复制图标。
4. 不需要再粘贴到微信或 Pinboard；Pinboard 会自动接收图片并放入当天画板的待整理区：`Screenshots\\YYYY-MM-DD.pinboard`。
5. 出现“已加入 YYYY-MM-DD.pinboard”通知后即可继续工作，稍后再整理画板。

取消截图或不执行复制时，接收器会在 120 秒后安静结束，不会生成空白内容。Pinboard 只在检测到这次 `Ctrl+Alt+A` 后读取下一张图片，不会收录其他普通复制内容。

## 复制文字自动收集

全新安装默认不收集复制的文字。需要此功能时，在“设置 → 截图接收”中勾选“自动收集复制的文字到 Text Clips 画板”，并选择“每天一张画板”。开启后，Pinboard 运行时（窗口打开或隐藏在系统托盘均可），每次复制的纯文字都会保存。当天第一次收录时，程序会创建 `Text Clips\YYYY-MM-DD.pinboard`；随后每段文字都会按捕获时间从上到下生成一张浅色卡片。左侧会有独立的 `Text Clips / 文字剪藏` 分栏，不与项目画板混在一起。

文字收集与 PixPin 截图接收互不影响。它忽略图片、文件拖放以及 Pinboard 自己的“复制文件路径 / 复制脚本”操作。设置中还提供独立暂停、常见敏感格式过滤和应用进程排除。升级时会保留已有的显式开关选择，并提示检查隐私设置。

这些防护不是绝对安全措施：Windows 不一定能报告剪贴板来源，规则也不可能识别所有密码或隐私内容。`.pinboard` 文件本身没有由 Pinboard 加密；若关闭“过滤常见凭据、验证码和银行卡号”，密码、令牌和验证码也会保存。处理敏感资料时，请暂停文字接收并使用 Windows 账户和磁盘加密保护文件。

## 可选：Pinboard 未运行时用 Ctrl+Alt+P 自动启动

如果你希望 Pinboard 完全没有运行时，按一个快捷键也能先启动接收器再截图，可在“设置 → PixPin 集成…”中复制下面脚本，并在 PixPin 的“配置 → 快捷键/动作”中新建自定义动作，绑定 `Ctrl+Alt+P`：

```javascript
pixpin.runSystem("explorer.exe \"pinboard://capture-next?source=pixpin\"")
pixpin.screenShot(ShotAction.Copy)
```

这一步不是普通 `Ctrl+Alt+A` 自动收录所必需的。如果没有自动找到便携版 PixPin，可在集成页点击“选择 PixPin.exe”，程序只在本机设置中记住该路径。若想备份或恢复 PixPin 配置，请先从托盘正常退出 PixPin；Pinboard 不会强制结束它，以免丢失现有贴图。

## 整理画板

- 中英文切换：界面首次启动默认为英文；在右上角“⋯ 更多”中选择中文或英文。选择会自动保存，画布工具栏也会同步切换。
- 左侧画板栏：按截图、文字文件夹和项目展开，单击名称直接切换；左上角的侧栏图标可收起或展开。日期按新到旧排列，较早月份默认折叠；手动画板按显示名称排列。
- 窗口与后台：点击右上角关闭会让 Pinboard 从任务栏消失并隐藏到系统托盘，同时继续在后台接收已启用的内容；单击系统托盘图标或再次启动 `Pinboard.exe` 可重新打开窗口。若要彻底退出，请在托盘菜单中选择“Exit / 退出”。
- 新建项目：点击侧栏顶部“＋”并选择“新建项目”，输入名称后创建；即使还没有画板，空项目也会显示。
- 新建画板：点击某个项目右侧的“＋”，即可直接在该项目中新建；`Ctrl+N` 则默认使用当前画板所属项目。
- 移动画板：点击画板右侧的“⋯”，选择目标项目。移动前会先保存当前画布，内嵌图片不会丢失。
- 归档画板：在“⋯”中选择“归档画板…”。画板会进入侧栏底部默认收起的“Archive / 归档”组；它仍是完整的单个 `.pinboard` 文件。打开归档画板的“⋯”，选择“恢复到项目…”即可放回正常项目。
- 删除画板：在“⋯”中选择“移到回收站…”。文件会进入 Windows 回收站而非直接永久删除；需要恢复时，请在 Windows 回收站中还原该 `.pinboard` 文件。
- 重命名画板：点击“⋯”或右键画板，选择“重命名显示名称”。它只改变 Pinboard 中看到的名字，磁盘上的文件名和路径不会改变。
- 查看真实路径：右键画板后，菜单顶部会显示实际文件路径；也可选择“在文件资源管理器中显示”或“复制文件路径”。
- 保持在最前：在右上角“⋯ 更多”中开启或取消置顶，设置会自动记住。
- 选择工具：点选图片后拖动；拖动边角改变大小。
- 抓手或 `Space + 拖动`：移动无限画布。
- 文字：选择文字工具后单击空白处输入说明；在“文字”分栏右上角的 `＋` 可新建文字文件夹或手动文字画板。
- 箭头：默认是粗糙度 0、2 px、单端直箭头。
- `Ctrl+V`：直接把剪贴板图片粘贴到当前画板。
- “一键到底”：画布右下角的 `↓` 直接定位当前画板中最下方的有效内容，不改变缩放；“更多”菜单中的“定位最新收录”则回到最后一次自动收录的内容。
- `Text Clips / 文字剪藏`：位于左侧独立分栏。每日画板显示为 `YYYY-MM-DD`，复制一段新文字时会继续从底部整齐追加，不会打乱已整理的卡片；旧版 `Text Clips.pinboard` 会显示为“历史文字”且不会自动迁移。
- 自动待整理布局：新截图会放进两列瀑布流中，自动选择较短的一列；截图之间保留间距，不会堆叠。已有截图不会被移动。
- “重置待整理区”：只改变两列下一张截图的起点，不移动已有内容。

## 项目、画板与接收目标

项目对应保存目录中的一个文件夹，画板对应一个可独立备份的 `.pinboard` 文件；这些文件名和目录由程序自动管理。画板显示名称存放在文件内部，因此重命名显示名称不会破坏外部路径或快捷方式。旧画板会显示在“默认项目”下，可使用画板右侧的“⋯”移动到新项目。

截图接收默认每天自动选择 `Screenshots\\YYYY-MM-DD.pinboard`，文件不存在时才会创建。文字接收同样默认写入 `Text Clips\\YYYY-MM-DD.pinboard`。要固定到某个画板，在左侧画板的 `⋯` 或右键菜单选择“设为截图接收目标”；文字画板则显示“设为文字接收目标”。该画板右侧会显示小蓝点；在它的菜单中选择“恢复每天自动接收”即可回到每日画板。

## 后台节省内存

开机后台启动时只运行收集器，不加载浏览器画布。窗口隐藏或最小化约 15 秒后，Pinboard 会先确认编辑保存，再释放浏览器和图片缓存；收集功能不暂停。再次打开时按需恢复当前画板、缩放与阅读位置，可能需要片刻。若保存失败或画板正在加载，程序会保留画布，不会为节省内存而丢弃尚未保存的内容。

## 搜索

- `Ctrl+F`：搜索当前画板中的文字备注与 OCR 文字。
- `Ctrl+Shift+F`：搜索项目库内的全部画板，包括项目子目录。
- 双击结果会打开相应画板并定位图片或文字附近。

OCR 在后台执行，不阻塞拖动与编辑。没有安装相应 Windows OCR 语言包时，图片仍会正常保存。

## 导入、导出与备份

- “导入 Obsidian”支持 `.excalidraw.md` 和标准 `.excalidraw`。
- “导出”支持 PNG、SVG 和标准 `.excalidraw`。
- “保存副本”在画板打开时创建一致的 `.pinboard` 备份。
- 日常备份只需复制单个 `.pinboard` 文件；不要只复制缓存目录。

若目标文件只读，Pinboard 会允许查看但阻止覆盖。保存失败时，未保存场景或截图会尝试写入 `%LocalAppData%\Pinboard\Recovery`。

## 退出

关闭主窗口会隐藏到系统托盘，以便持续接收 PixPin 截图和已明确启用的复制文字。要完全退出，请右键托盘中的 Pinboard 图标并选择“退出”。
