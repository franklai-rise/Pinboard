# Pinboard 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+A` | 像平时一样启动 PixPin；截图复制后自动收录到 Pinboard（Pinboard 需在后台运行） |
| `Ctrl+Alt+P` | 可选：由 PixPin 自定义动作启动 Pinboard 后截图 |
| `Ctrl+N` | 在程序内新建项目画板 |
| `Ctrl+O` | 打开画板 |
| `Ctrl+V` | 粘贴剪贴板图片或内容到画布 |
| `Ctrl+F` | 搜索当前画板 |
| `Ctrl+Shift+F` | 搜索全部项目与画板 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Space + 拖动` | 平移画布 |
| 鼠标滚轮 | 纵向移动画布 |
| `Ctrl + 鼠标滚轮` | 缩放画布 |
| `Delete` | 删除选中元素 |
| `Esc` | 取消当前工具或选择 |

Excalidraw 顶部工具栏还提供选择、抓手、矩形、菱形、椭圆、箭头、直线、自由笔、文字、图片和橡皮擦。

项目通过左侧“＋ 项目”创建；窗口置顶通过右上角“已置顶”切换。
