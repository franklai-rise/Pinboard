# Pinboard 0.7.3

## 更轻的后台收集

- 登录后在后台启动时，不加载浏览器画布。截图与文字收集继续运行。
- 关闭窗口或最小化 15 秒后，先确认编辑已经保存，再释放画布浏览器及其图片缓存。保存失败会保留画布，避免丢失更改。
- 重新打开窗口时按需载入画布，恢复休眠前的位置与缩放；重新载入可能需要片刻。
- 切换画板时释放上一张画板的解码图片与文件缓存。
- 打开画板只读取当前内容引用的图片；恢复点用到的历史资源仍留在文件中。
- 定位、OCR 搜索定位仅查询场景和图片引用；压缩/解压采用流式读写，减少完整缓冲副本。
- 后台暂停刷新侧栏，前台合并文件变动刷新并缓存显示名称。

## 更安静的界面

- 单行工具栏、清晰标题与保存状态、灰白侧栏、蓝色选中状态、小型接收标记。
- 文件操作在悬停、键盘焦点或右键时出现。左侧顶部的加号集中创建画板、项目和文字文件夹。
- 文字文件夹单独显示，空文件夹仍可使用；文字板的显示名称正确读取元数据。
- 较早日期按月份分组并默认折叠，当前窗口内保留用户的分组展开选择。
- 「一键到底」位于画布内，避免被原生浏览器窗口遮住；保持缩放，并定位横向分散内容和长文字的底部。
- 新文字卡片采用灰白底色和低对比边框。旧卡片保留用户原有样式。
- 同一矢量设计用于应用、窗口、任务栏和托盘图标。

自动接收目录、固定目标、语言、隐私选择和开机启动沿用已有设置。顶部「更多」可找到设置、语言、导入、导出和保存副本。

## 验证

- 核心回归测试与前端保存、定位测试通过。
- 独立桌面验证覆盖无画布后台启动、无空白文件、真实 WebView 反复切换、底部定位、保存确认、休眠释放、休眠中收录、恢复阅读位置及跳过保存时禁止释放。
- 实际内存取决于画板图片分辨率、Windows 缓存与 OCR 工作负载。后台释放浏览器能降低常驻占用；打开大型图片画板时仍需保留可编辑图片。
